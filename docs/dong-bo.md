# Đồng bộ 2 nơi: chat làm việc ↔ GitHub

Dự án AI Free được theo dõi và sử dụng ở hai nơi song song:

1. **Khung chat làm việc** — nơi thảo luận, thống nhất và lưu bộ nhớ vận hành
   đầy đủ (kể cả chi tiết nội bộ không công khai).
2. **Repo GitHub này** — bản công khai theo chuẩn chuyên nghiệp: hiến chương,
   kiến trúc, luật vận hành và changelog.

## Quy tắc

- **Mọi thảo luận đã thống nhất đều được cập nhật ở cả hai nơi.** Thỏa thuận
  trong chat mà chưa lên GitHub là chưa hoàn tất việc ghi nhận; nội dung trên
  GitHub mà chat chưa thống nhất thì không có giá trị.
- **Chat là nơi ra quyết định, GitHub là nơi công bố quyết định.** Không dùng
  GitHub để quyết định thay chat, và không dùng chat để giữ riêng quyết định
  đã công bố.
- **Workspace là bản đầy đủ, GitHub là bản công khai.** Bản công khai lược các
  chi tiết vận hành nội bộ (đường dẫn máy cục bộ, mã triển khai, thông tin tài
  khoản, dữ liệu cá nhân/tài chính). Lược bỏ không làm thay đổi nội dung thỏa
  thuận; nếu có xung đột, bản chat/workspace được ưu tiên đối chiếu.
- **Không bao giờ đẩy secret lên GitHub.** Password, API key, token, mã 2FA,
  email/SĐT cá nhân và thông tin tài khoản nội bộ không xuất hiện ở đây dưới
  bất kỳ hình thức nào.
- **Lời ngỏ bất biến, Khung sống, ROUTER duyệt tay.** Xem CONTRIBUTING.md.
- **Mỗi lần cập nhật GitHub là một commit có thông điệp rõ ràng** (thay đổi gì,
  theo thỏa thuận nào, ngày nào), để lịch sử repo đọc được như nhật ký dự án.
